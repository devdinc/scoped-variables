# Scoped Variables

Skript package maintained by devdinc.

## Installation

`package install https://github.com/devdinc/scoped-variables`

Requires Skript 2.15+ and skript-reflect 2.6+.

## Layout

- Source: `src/scoped-variables.sk`
- Tests: `-tests/`

Part of the [devdinc Skripts collection](https://github.com/devdinc/skripts).
